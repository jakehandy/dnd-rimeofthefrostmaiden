# Sessions

Create one file per session using `templates/session-note.md`.
Naming:
- `session-001.md`
- `session-002.md`

## Combat log convention (ongoing)
- During live play updates, append short combat log lines to the active session file.
- Recommended format:
  - `Round X - [Actor] - [Action/Effect] - [Resulting state change]`
- Include HP deltas and caps when relevant (example: `+15 HP`, capped at max HP).
